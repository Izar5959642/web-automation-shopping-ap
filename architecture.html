Legend

automation — Browser (outside the chain)
solid arrow = imports from  |  dashed = uses types

Architecture Rules

  • The main chain flows one way: ui → api → services → domain
  • automation is a side branch — only services uses it, no other layer
  • domain has zero imports from other layers — it may import within itself (e.g. Order imports Product)
  • To add a new site: extend BaseScraper — never modify it (Open/Closed Principle)
  • Every layer is a class (OOP). One class per file.
